= Messages
:description: How the edge of an application without Spring turns the code and the client arguments of a violation into a message in the language of the caller.
include::partial$javadoc.adoc[]

Rules report codes and arguments, and the edge of the application, where it answers the caller, turns them into a message.
A rule then needs no text and no language, and the same violation reads in the language of each caller.

The lambda calls `ResourceBundle.getBundle` from the application's own module, which is what lets it find the bundles on the module path.
`Locale.ENGLISH` says that the base bundle is written in English, for the numbers and dates of its messages, as <<_in_which_locale>> shows.

A caller whose language has no bundle reads the base bundle, the one without a locale in its name, even on a server whose own default locale is Turkish: the example checks that a French caller reads English there.
Without a base bundle, `ofResourceBundles` refuses the family.

== Templates

`+{name}+` writes the value of an argument as `String.valueOf` writes it; a placeholder with a type formats a number or a date, as the next section shows.
Template text is written as it reads, apostrophes included, and `+{{+` or `+}}+` writes a brace where it would otherwise read as part of a placeholder.
A name that the violation does not carry stays in the message as it is, and a code without a template reads as the code, so a mistake in a template shows in the answer rather than failing the call.

With `1500` as its client argument `limit`, the message reads `At most 1,500 vehicles at once`, and `Bir seferde en fazla 1.500 araç` for a Turkish caller.
The client arguments of the answer keep their values, so a client still reads `1500` as a number.

[cols="2,5"]
|===
|Placeholder |Writes

|`+{amount,number}+` |A number. A `BigDecimal` keeps its scale, so `12.50` reads `12.50`; other numbers get at most three fraction digits.
|`+{count,number,integer}+` |A number rounded to a whole one.
|`+{rate,number,percent}+` |A number as a percentage: `0.15` reads `15%`.
|`+{when,date}+` |A `LocalDate`, or the date of a `LocalDateTime`, `ZonedDateTime` or `OffsetDateTime`.
|`+{at,time}+` |A `LocalTime` or an `OffsetTime`, or the time of a date and time.
|`+{at,datetime}+` |A `LocalDateTime`, `ZonedDateTime` or `OffsetDateTime`.
|===

A date or a time takes a style after its type, `short`, `medium`, `long` or `full`, as in `+{when,date,short}+`; without one it is `medium`.
The long and full styles of a time, or of a date and time, write the name of its zone, so they take a `ZonedDateTime`.
An `Instant` or a `java.util.Date` has no date until it is given a zone, so a rule passes a `ZonedDateTime` instead.

A value that its placeholder cannot format, such as a text in `+{limit,number}+` or a `BigDecimal` with more than 1,000 digits before or after its point, is written as `String.valueOf` writes it and logged at DEBUG, and a type or a style that Muster does not know stays in the message as it is: as with an unknown name, a mistake shows in the answer rather than failing the call.
The types and styles are those of `java.text.MessageFormat`, without its currencies, patterns and choices, and with `datetime` added.

=== In which locale

The values are formatted in the locale of the template that was found, so that the numbers of a sentence read as its language writes them.
A template in the caller's language is formatted in the caller's locale, region included, whether it comes from the bundle of that language or from a base bundle written in it: in the example, whose base bundle is English, a British caller gets `12/11/2026` for a short date, and an American one `11/12/26`.
A template from the base bundle that a caller of another language reads is formatted in the locale that `ofResourceBundles` is given for the base bundle, so a German caller, who has no bundle, reads `At most 1,500 vehicles at once` rather than an English sentence with the German `1.500`.
Without that locale, the base bundle is formatted in the root locale, which belongs to no language and writes `1,500` and `2026-11-12` for every caller it answers.

== From elsewhere

Templates kept in a database table, or in the message source of a framework, reach Muster through link:{javadoc-core}/spi/MessageResolver.html[`MessageResolver.ofTemplates`], which asks for the template of a code in a locale and fills it in the same way.
Such a lookup does not tell the locale of the template it found, so the values are formatted in the caller's locale.
An application with its own way of writing messages implements `MessageResolver` itself.

== Client and internal arguments

A message is made from client arguments only.
Internal arguments, such as the owner of a vehicle that the caller may not rename, never reach it.
